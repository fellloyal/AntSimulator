# 蚂蚁拟真改进方案

## 1. 改进目标

将蚂蚁从当前的"纯色矩形"升级为具有三段体结构、触角、有机运动的拟真蚂蚁，同时改进信息素采样机制为双触角对比采样，使蚂蚁行为更接近真实生物学。

## 2. 当前问题分析

| 问题 | 现状 | 目标 |
|------|------|------|
| 外观 | 纯色旋转矩形 (3×4.7px) | 三段体（头/胸/腹）+ 触角 + 腿 |
| 信息素采样 | 单点随机采样 32 个方向 | 双触角左右对比采样 |
| 运动 | 匀速直线 + 碰壁反弹 | 行走摆动 + 负载变速 + 偶尔停顿 |
| 蚁巢 | 纯色圆 + 白色进度环 | 土堆渐变 + 入口暗点 |
| 死亡 | 立即消失 | 尸体淡出 |

## 3. 改进详情

### 3.1 三段体外观 + 触角渲染 (P0)

**影响文件**: `src/render/ColonyRenderer.ts`, `src/simulation/Ant.ts`

**蚂蚁身体结构**:
```
     触角L   触角R
      \     /
       头 (小椭圆)
       |
       胸 (中椭圆)
      /|\
     腿1 腿2 腿3
       |
       腹 (大椭圆) ← 蚁群颜色
```

**尺寸定义** (工蚁):
- 头部: 半径 1.5px
- 胸部: 半径 1.8px
- 腹部: 半径 2.5px（椭圆形，长轴 3.0px）
- 触角: 长度 3.0px，从头部伸出，夹角 ±30°
- 腿: 3 对，从胸部伸出，长度 2.0px，行走时交替摆动

**兵蚁**: 所有尺寸 × 2.0

**携带食物**: 头部前方显示绿色小圆（食物颗粒），大小 1.5px

**渲染方式**: 使用 Canvas 2D 的 `ellipse()` 和 `lineTo()` 绘制，避免图片资源依赖。

### 3.2 双触角信息素采样 (P0)

**影响文件**: `src/simulation/WorkerUpdater.ts`, `src/simulation/Ant.ts`

**原理**: 真实蚂蚁用左右两根触角分别感知信息素浓度，根据浓度差决定转向方向。

**实现**:
- 在蚂蚁前方左右两侧各设置一个采样点（模拟触角位置）
- 触角间距: 约 3px，偏转角 ±25°
- 采样距离: 8-15px（触角长度范围）
- 比较左右触角感知的信息素强度差
- 强度差越大，转向幅度越大
- 保留少量随机采样作为"探索"行为

**新采样流程**:
```
1. 计算左触角采样点位置
2. 计算右触角采样点位置
3. 分别获取两侧信息素强度
4. 计算强度差 → 转向力
5. 叠加少量随机噪声
6. 更新方向
```

### 3.3 有机运动 (P1)

**影响文件**: `src/simulation/Ant.ts`, `src/common/Direction.ts`

**行走摆动 (wobble)**:
- 蚂蚁身体在前进方向上做正弦摆动
- 摆动幅度: ±3°
- 摆动频率: 约 4Hz
- 新增属性: `wobblePhase` (随机初始相位), `wobbleFreq` (频率)

**负载变速**:
- 空载速度: 40 px/s (保持不变)
- 携带食物速度: 32 px/s (0.8×)
- 新增方法: `getMoveSpeed(): number` 根据 phase 返回速度

**偶尔停顿**:
- 概率: 每秒约 5% 的几率短暂停顿
- 停顿时长: 0.1-0.3 秒
- 新增属性: `pauseTimer`, `isPaused`

**避障改进**:
- 碰壁后不是立即反弹，而是逐渐转向远离墙壁的方向
- 增加"试探"行为：碰壁后先小幅转向再继续

### 3.4 蚁巢拟真渲染 (P1)

**影响文件**: `src/render/ColonyRenderer.ts`

**土堆效果**:
- 使用径向渐变绘制蚁巢土堆
- 中心深色（入口），边缘浅色（土壤）
- 入口处有一个暗色小圆点
- 周围有散落的土粒纹理（随机小点）

**进出效果**:
- 蚂蚁接近蚁巢时方向收敛（已有逻辑）
- 蚁巢入口处有微弱的发光效果

### 3.5 死亡淡出效果 (P2)

**影响文件**: `src/render/ColonyRenderer.ts`, `src/simulation/Ant.ts`

**实现**:
- 蚂蚁死亡后进入 `Dying` 状态（新增），持续 2 秒
- 渲染时使用递减的 alpha 值
- 2 秒后进入 `Dead` 状态，不再渲染
- 尸体颜色变暗（降低饱和度）

## 4. 数据结构变更

### Ant 类新增属性

```typescript
// 行走摆动
wobblePhase: number;    // 随机初始相位
wobbleFreq: number;     // 摆动频率

// 偶尔停顿
pauseTimer: number;     // 停顿计时器
isPaused: boolean;      // 是否正在停顿

// 死亡淡出
dyingTimer: number;     // 淡出计时 (0 = 刚死, 2.0 = 完全消失)
```

### Mode 枚举变更

```typescript
export enum Mode {
  ToHome = 0,
  ToFood = 1,
  ToEnemy = 2,
  Refill = 3,
  Flee = 4,
  ToHomeNoFood = 5,
  Dying = 6,    // 新增：死亡淡出状态
  Dead = 7,     // 原来的 6 改为 7
}
```

## 5. 性能考虑

- 三段体渲染比矩形更复杂，但蚂蚁数量不变（~1000/colony），Canvas 2D 可承受
- 双触角采样比 32 点随机采样更高效（只需 2-4 个采样点 + 少量探索）
- 行走摆动仅影响渲染角度，不增加计算量
- 死亡淡出需要额外渲染 dying 状态的蚂蚁，但数量极少

## 6. 实施顺序

1. **P0**: 三段体外观 + 触角渲染 → 立即可见的视觉提升
2. **P0**: 双触角采样 → 行为更自然
3. **P1**: 有机运动 → 运动更真实
4. **P1**: 蚁巢拟真 → 场景更完整
5. **P2**: 死亡淡出 → 细节打磨
