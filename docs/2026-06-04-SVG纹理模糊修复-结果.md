# SVG 纹理模糊修复 - 实施结果 - 2026-06-04

## 根因

`AssetRegistry` 把每个 SVG 缓存到 `cellSize * 2` 大小的位图：
- 编辑器 cellSize=4 → 缓存 8x8 位图
- 画到 4x4 食物格：8x8 → 4x4 缩小（默认 low 质量，模糊）
- 画到 16x16 食物块：8x8 → 16x16 放大（很模糊）

SVG 矢量缩放无失真的优势被位图缓存吃掉了。

## 修复

[AssetRegistry.ts](file:///d:/Projects/ant-cn/src/render/AssetRegistry.ts)：

1. 缓存尺寸固定为 128x128（不再依赖 cellSize）
2. 缓存 ctx 设置 `imageSmoothingEnabled = true` + `imageSmoothingQuality = 'high'`
3. drawTile 时对目标 ctx 也设置同样的高质量
4. setCellSize 不再清空缓存（缓存独立于 cellSize）

## 效果对照

| 场景 | 原（cellSize*2 缓存） | 新（128x128 缓存） |
|------|---------------------|-------------------|
| 4x4 食物块（16px） | 8→16 放大模糊 | 128→16 高质量缩小，锐利 |
| 1x1 食物（4px） | 8→4 缩小，low 质量 | 128→4 高质量缩小，锐利 |
| 地形大块（40px） | 8→40 放大模糊 | 128→40 高质量缩小，锐利 |
| 障碍物大块（24px） | 8→24 放大模糊 | 128→24 高质量缩小，锐利 |

## 验证

- `npm run check` ✅
- 所有缓存键不变，调用方无需改动
- 内存开销：每个 tile 从 8x8 (256B) 升到 128x128 (64KB)，约 250 倍
- 但 tile 数量有限（20 个食物 + 4 地形 + 4 障碍 + 几个装饰），总内存 < 2MB
