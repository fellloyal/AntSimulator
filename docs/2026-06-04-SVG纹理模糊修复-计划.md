# SVG 纹理模糊修复 - 2026-06-04

## 问题

用户反馈：即便把食物改为 NxN 块，SVG 纹理仍然模糊。

## 根因

`AssetRegistry` 当前把 SVG 缓存为 `cellSize * 2` 大小的位图：
- 编辑器 cellSize=4 → 缓存 8x8 像素
- 模拟器 cellSize=4 → 缓存 8x8 像素
- 食物 4×4 块需要画 16x16 像素 = 8x8 → 16x16 放大，模糊
- 食物 1×1 块需要画 4x4 像素 = 8x8 → 4x4 缩小，也模糊

而 SVG 的优势本就是矢量缩放无失真，但这里被预渲染成小位图后就失去了。

## 修复方案

1. **缓存尺寸改为固定高分辨率**（如 128x128）
2. **启用高质量缩放** `imageSmoothingQuality = 'high'`
3. **drawTile 时也设置高质量**（避免被目标 ctx 关闭的 smoothing 影响）
4. **移除 setCellSize 时清空缓存**（缓存与 cellSize 无关）

### 新逻辑

```typescript
const TILE_RENDER_SIZE = 128;

preloadSVG(svg, key):
  canvas.width = TILE_RENDER_SIZE;
  canvas.height = TILE_RENDER_SIZE;
  ctx.imageSmoothingEnabled = true;
  ctx.imageSmoothingQuality = 'high';
  // ... 加载 SVG → 渲染到 128x128 画布

drawTile(ctx, key, x, y, size):
  ctx.imageSmoothingEnabled = true;
  ctx.imageSmoothingQuality = 'high';
  ctx.drawImage(tile.canvas, 0, 0, 128, 128, x, y, size, size);
```

## 效果

| 场景 | 原 | 新 |
|------|---|---|
| 1×1 食物 | 8→4 缩小（默认 low） | 128→4 缩小（high） |
| 2×2 食物 | 8→8 同尺寸（已模糊） | 128→8 缩小（清晰） |
| 3×3 食物 | 8→12 放大（模糊） | 128→12 缩小（清晰） |
| 4×4 食物 | 8→16 放大（很模糊） | 128→16 缩小（清晰） |
| 地形大块 | 8→40 放大（模糊） | 128→40 缩小（清晰） |
| 障碍物大块 | 8→24 放大（模糊） | 128→24 缩小（清晰） |
