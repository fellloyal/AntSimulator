### 交互逻辑

1. **比例切换**：点击 1:1/4:3/16:9/9:16/21:9 → 宽不变，高按比例自动重算
2. **改宽**：输入新宽 → 高自动重算（按当前比例）
3. **改高**：输入新高 → 宽自动重算（按当前比例）
4. **应用尺寸**：点击绿色按钮 → 调用 `setEditorMap` 应用新尺寸
5. **预设**：点击 240×135 等预设 → 立即应用

### 比例自动推断

进入编辑器时，根据当前 `editorMapWidth/Height` 自动推断比例（取最接近的预设）。

### 移除的旧 UI

原顶部"小/中/大"3 个预设按钮已移除，所有尺寸控制统一在右侧面板。

### 边界保护

- 最小尺寸：100×100
- 最大尺寸：6000×6000
- 超出范围时 input clamp 到边界
- 应用按钮在尺寸无效时不响应
