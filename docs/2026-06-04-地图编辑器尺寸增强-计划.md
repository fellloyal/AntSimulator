# 地图编辑器增强 - 自定义尺寸和比例 - 2026-06-04

## 需求

1. **自定义地图尺寸** — 用户可按比例输入宽高（如选 9:16，输入宽，自动算高）
2. **极小预设** — 增加比 960×540 更小的预设（如 240×135）
3. **9:16 比例覆盖** — 各档位都提供 16:9 和 9:16 两种比例

## 设计

### 比例预设（5 种常用）

| 比例 | 名称 | 适用场景 |
|------|------|----------|
| 1:1 | 正方形 | 测试/小型场景 |
| 4:3 | 传统 | 经典显示器 |
| 16:9 | 横屏 | 桌面浏览器/电视 |
| 9:16 | 竖屏 | 移动设备 |
| 21:9 | 超宽 | 带鱼屏 |

### 尺寸档位（4 档 × 2 比例）

| 档位 | 16:9 | 9:16 |
|------|------|------|
| 极小 | 240×135 | 240×426 |
| 小 | 480×270 | 480×854 |
| 中 | 960×540 | 960×1706 |
| 大 | 1920×1080 | 1920×3408 |

### UI 布局

```
[ 返回 ] [ 地图名 ]  ←top bar
  ┌────────────────────────────────────┐
  │  尺寸                                │
  │  比例: [1:1] [4:3] [16:9] [9:16] [21:9]  │
  │  宽:   [____] px                    │
  │  高:   [____] px (自动，按比例计算)    │
  │  [ 应用尺寸 ]                         │
  │  ───────                            │
  │  预设:                               │
  │  极小: [240×135] [240×426]            │
  │  小:   [480×270] [480×854]            │
  │  中:   [960×540] [960×1706]           │
  │  大:   [1920×1080] [1920×3408]        │
  └────────────────────────────────────┘
```
