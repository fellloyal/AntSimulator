# 食物 SVG 重设计 - 实施结果 - 2026-06-04

## 改进要点

[FoodSprites.ts](file:///d:/Projects/ant-cn/src/render/assets/FoodSprites.ts) - 12 个 SVG 全部重画，统一 viewBox 32×32。

### 苹果 🍎 — 顶部凹陷 + 茎 + 叶
- **旧**：圆形红 + 一个绿色椭圆（像番茄）
- **新**：圆身带顶部凹陷（dimple path）+ 棕色短茎 + 倾斜的绿叶
- 凹陷用 `M14,9.8 Q16,6.5 18,9.8` 路径实现
- 3 个尺寸都有茎叶，large 是 2 个苹果

### 鸡腿 🍗 — 椭圆肉 + 末端白骨
- **旧**：1-2 个圆形肉块 + 1-2 个小白椭圆
- **新**：整个组件用 `rotate(-25)` 倾斜，肉块椭圆 + 焦色纹理 + 白色骨头（长矩形）+ 骨关节（末端圆角）
- 3 个尺寸都用 `<g transform="rotate">` 包裹保证角度一致
- large 是 2 根鸡腿（一大一小）

### 面包 🍞 — 椭圆 + 3 道斜切痕
- **旧**：椭圆 + 几粒芝麻
- **新**：椭圆 + 顶部 3 道斜线（`path d="M9,13.5 L12,11"` 形式） + 芝麻 + 边缘焦色
- 切痕是面包的标志性特征（baker's score）
- large 是长棍 + 圆面包

### 浆果 🫐 — 多果成簇 + 茎网
- **旧**：2-5 个紫色圆，分布在画面上
- **新**：顶部绿叶 + 茎网（多条 `path` 线条） + 浆果成簇
- 每颗浆果有单独高光
- large 是 6 颗 + 顶部叶簇

## 验证

- `npm run check` ✅
- 所有 12 个 SVG 用 viewBox 32×32 重新设计
- `FOOD_SPRITES` 接口和 `foodSizeFromQty` 未变，调用方无需改动

## 视觉改进（用户角度）

- 苹果：能立即识别（凹陷+茎+叶）
- 鸡腿：明显是"肉+骨头"造型，不再像圆球
- 面包：切痕是面包的视觉签名
- 浆果：成簇带茎像葡萄/蓝莓，不再像散落的圆点
