# 食物 SVG 重设计 - 2026-06-04

## 问题

当前食物 SVG 看起来都是圆形色块，辨识度低：
- 苹果：圆形无顶部凹陷，看不出是苹果
- 鸡腿：圆形 + 一个小白点，不像鸡腿
- 面包：椭圆形，无标志性的切痕
- 浆果：2-3 个圆，没有茎

## 重设计目标

每种食物必须有**标志性形状特征**，用户通过形状和颜色能秒辨认。

### 苹果 🍎
- 圆形身体 + **顶部凹陷**（dimple）
- 棕色**短茎**
- 绿色**叶子**（一侧）
- 红色高光
- 大：2 个苹果叠加

### 鸡腿 🍗
- 椭圆肉块（带角度倾斜）
- 末端**白色骨头**（明显突出）
- 骨头末端有**关节凸起**
- 棕色肉 + 白骨
- 大：2 根鸡腿

### 面包 🍞
- 椭圆/梭形面包
- 表面有 **3 条斜切痕**（baker's score）
- 金黄色 + 边缘焦色
- 大：长棍 + 圆面包

### 浆果 🫐
- 多个小圆果**成簇**（不是单独 1 个）
- **茎连接**各果
- 深紫/深蓝色
- 每颗有高光
- 大：5-6 颗 + 顶部叶

## 实施

- 使用统一 viewBox 32×32（更精细）
- 大中小 3 尺寸：细节递增 / 数量递增
- 12 个 SVG 全部重画
