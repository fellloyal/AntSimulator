# 食物块大小增强 - 2026-06-04

## 问题

地图编辑器中，食物占 1 格（4×4 px）时，即便画了 SVG 纹理（鸡腿/苹果等）也看不清是哪种食物。

## 方案

允许食物占 N×N 格（1-4），让食物纹理有足够空间显示。

## 数据模型

- 现有 `grid[idx]` 存食物量（qty+1），不变
- 现有 `foodTypeRef` 存食物类型，不变
- 新增 UI 控件：`foodBlockSize` (1-4)
- 当用户点画食物时，paint 工具填充 N×N 块
- 每格存储 `qty=1` + `foodType`

## 渲染层（编辑器 + 模拟器）

**核心：找到食物块的"锚点"（左上角），在那里画一个尺寸 = blockSize × cellSize 的精灵**

```typescript
function isAnchor(grid, x, y, w):
  // 锚点 = 左/上方无同类型食物
  if (x > 0 && grid[x-1, y].food > 0 && grid[x-1, y].foodType === grid[x, y].foodType) return false;
  if (y > 0 && grid[x, y-1].food > 0 && grid[x, y-1].foodType === grid[x, y].foodType) return false;
  return true;

function findBlockSize(grid, x, y, w, h):
  // 向右/下找到连续同类型食物的尺寸
  let size = 1;
  while (x + size < w && grid[x+size, y].food > 0 && grid[x+size, y].foodType === grid[x, y].foodType) size++;
  // 注：使用方块 size × size（不严格计算矩形）
  return size;
```

**编辑器和模拟器都用同一套 dedup 逻辑**。

### Editor render
```javascript
// 找到食物锚点，绘制
for each visible cell (x, y):
  if (grid[idx] < 2) continue;  // 不是食物
  if (y > 0 && grid[(y-1)*gridW + x] >= 2 && same type) continue;  // 上方有同类型
  if (x > 0 && grid[y*gridW + (x-1)] >= 2 && same type) continue;  // 左方有同类型
  // 是锚点 - 找块大小
  let size = 1;
  while (x + size < gridW && grid[y*gridW + (x+size)] >= 2 && same type) size++;
  // 画食物
  const drawSize = size * CELL_SIZE;
  const drawX = x * CELL_SIZE;
  const drawY = y * CELL_SIZE;
  AssetRegistry.drawTile(ctx, key, drawX, drawY, drawSize);
```
