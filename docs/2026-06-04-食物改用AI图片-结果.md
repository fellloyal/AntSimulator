# 食物改用 AI 图片 - 实施结果 - 2026-06-04

## 核心改动

按 [2026-06-04-食物改用AI图片-计划.md](./2026-06-04-食物改用AI图片-计划.md) 完成。

### 1. AssetRegistry 拆分

[AssetRegistry.ts](file:///d:/Projects/ant-cn/src/render/AssetRegistry.ts)：
- 提取 `preloadImage(url, key)` — 通用图片加载（接受 URL/data URL/Blob URL）
- `preloadSVG(svg, key)` 保留，内部转 Blob URL 后调用 `preloadImage`
- 缓存 canvas 仍为 128x128 高分辨率
- `crossOrigin = 'anonymous'` 支持跨域图

### 2. FoodSprites 改用 API

[FoodSprites.ts](file:///d:/Projects/ant-cn/src/render/assets/FoodSprites.ts)：
- 4 种食物各 1 个 image URL（`https://trae-api-cn.mchost.guru/api/ide/v1/text_to_image?prompt=...&image_size=square`）
- small/medium/large 共用同一张图，渲染时按尺寸缩放
- 新增 `preloadFoodSprite(reg, type, size, key)` 辅助，自动判断 URL/SVG

## 性能

- 4 个 URL 一次性预加载（去重后实际只 4 个 unique URL）
- 浏览器内置 HTTP 缓存
- 128x128 缓存 canvas 缩放到任意目标尺寸
- 首次加载需 1-3 秒（API 生成），后续即时

- 编辑器/模拟器接口未变

## 备选方案（如果 AI 图不满意）

1. **手画更好 SVG**：增加节点密度 + 渐变 + 阴影
2. **混合方案**：保留 base64 嵌入的 emoji 风格 icon（如 Twemoji）
3. **多次生成选最佳**：API 支持相同 prompt 不同 seed 的输出
