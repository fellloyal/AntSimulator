# 地图尺寸变化后自动居中 - 2026-06-05

## 背景

用户反馈：在修改地图尺寸后，地图中心应对应页面中心，不然容易找不到地图。

## 现状分析

`MapEditor.tsx` 视口默认 `{ offsetX: 0, offsetY: 0, zoom: 1 }`，意味着地图以左上角对齐画布左上角。当画布大于地图时，地图缩在角落；当画布小于地图时，地图中心偏离视口，用户拖动一下才找得到。

## 方案

添加一个 useEffect，监听 `editorMapWidth` 和 `editorMapHeight` 变化，重新计算 viewport offset 使地图中心对齐画布中心：

```ts
vp.offsetX = cw / 2 - (editorMapWidth / 2) * vp.zoom;
vp.offsetY = ch / 2 - (editorMapHeight / 2) * vp.zoom;
```

放在 canvas resize useEffect 之后（保证 canvas 已被布局，能拿到 clientWidth/clientHeight）。

## 触发时机

| 场景 | 触发 |
|------|------|
| 首次打开编辑器 | ✓ useEffect 在 mount 时运行 |
| 切换预设尺寸 | ✓ setEditorMap → store 更新 → effect 重跑 |
| 自定义尺寸 | ✓ 同上 |
| 用户手动拖动 | ✗ 不重置（offset 已被用户改变，不在依赖里） |
| 窗口缩放 | ✗ 不重置（保留用户当前的 pan 位置） |
| 鼠标滚轮缩放 | ✗ 不重置（zoom 不在依赖里） |

## 修改的文件

- `src/pages/MapEditor.tsx` — 新增居中 useEffect

## 验证

- `npm run check` 通过
- 用户体验：现在打开编辑器、切换预设、改自定义尺寸，地图中心始终在画布中心
