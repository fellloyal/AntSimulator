# 地图编辑 Shift 直线绘制 - 2026-06-05

## 背景

用户反馈：编辑地图障碍物、地形时，应提供按住 Shift 键可以拉水平或竖直的直线生成。

## 行为

- Shift + 左键按下：记录起点网格坐标到 `shiftAnchorRef`
- 拖动期间：从 anchor 到当前鼠标位置，按**主轴**（|dx| vs |dy|）拉水平或竖直的直线
- 释放鼠标：清除 anchor，回到正常模式
- 食物工具（NxN 块）不支持 Shift 直线（无直线语义）

主轴判定：
- `|dx| >= |dy|` → 水平：固定 y = anchorY，沿 x 走
- `|dy| > |dx|` → 竖直：固定 x = anchorX，沿 y 走

## 实现

### 关键重构

把原 `paint(canvasX, canvasY)` 拆成两个函数：
- `paintAtCell(cx, cy)`：在指定网格坐标处应用当前工具 + 笔刷
- `paint(canvasX, canvasY)`：把屏幕坐标转网格坐标后调用 `paintAtCell`

这样 `paintShiftLine` 可以按单元逐个调用 `paintAtCell`，复用笔刷逻辑（带 brushSize 厚度）。

### 新增函数

```ts
const paintShiftLine = useCallback((anchorX, anchorY, targetX, targetY) => {
  const dx = targetX - anchorX;
  const dy = targetY - anchorY;
  if (dx === 0 && dy === 0) {
    paintAtCell(anchorX, anchorY);
    return;
  }
  if (Math.abs(dx) >= Math.abs(dy)) {
    const sign = dx >= 0 ? 1 : -1;
    for (let x = anchorX; x !== targetX + sign; x += sign) {
      paintAtCell(x, anchorY);
    }
  } else {
    const sign = dy >= 0 ? 1 : -1;
    for (let y = anchorY; y !== targetY + sign; y += sign) {
      paintAtCell(anchorX, y);
    }
  }
  render();
}, [paintAtCell, render]);
```

### 鼠标事件修改

- `handleMouseDown`：Shift+左键时记录 anchor 并画起点；否则清 anchor
- `handleMouseMove`：drawing 中若 anchor 存在，调 `paintShiftLine`；否则调 `paint`
- `handleMouseUp`：清 anchor
