# 地形与水/砖混合时变红砖修复 - 实施结果 - 2026-06-05

## 改动

| 文件 | 改动 |
|------|------|
| `src/pages/MapEditor.tsx` | `paintAtCell` 地形分支对称清除旧墙/障碍物标记 |

## 根因

地形工具绘制时只设置 `terrainRef`，不重置 `grid` 和 `obstacleRef`。如果该格之前是砖块（`grid=1, obstacleRef=1`），画沙后这些标记仍保留，ObstacleRenderer 继续把红砖画在上面。

## 修复

```ts
} else if (tool === 'terrain') {
  if (terrainType === 2) {
    grid[idx] = 1;  // 水：不可通过
    obstacleRef.current.delete(idx);
  } else {
    grid[idx] = 0;  // 非水：可通行
    obstacleRef.current.delete(idx);
  }
  terrainRef.current.set(idx, terrainType);
}
```
