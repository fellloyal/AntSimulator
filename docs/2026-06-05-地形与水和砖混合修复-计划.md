# 地形与水/砖混合时变红砖修复 - 2026-06-05

## 背景

用户反馈：编辑地图时沙地和水放一起变红砖。

## 根因

[paintAtCell](file:///d:/Projects/ant-cn/src/pages/MapEditor.tsx#L362) 中地形工具的绘制只设置 `terrainRef`，不重置 `grid` 和 `obstacleRef`：

```ts
} else if (tool === 'terrain') {
  terrainRef.current.set(idx, terrainType);
  if (terrainType === 2) {
    grid[idx] = 1;  // 水才处理
  }
  // 沙/草/石时 grid 和 obstacleRef 都不动
}
```

复现路径：
1. 用户在 (5,5) 画砖块：`grid=1, obstacleRef=1, terrainRef=undefined`
2. 用户在同一格画沙地：`terrainRef=1`，但 `grid=1, obstacleRef=1` 保留
3. 渲染：terrain 先画沙，obstacle 在 `grid=1` 的格子上再画红砖覆盖 → 看起来还是红砖

墙/障碍物工具绘制时正确地 `terrainRef.current.delete(idx)`，但地形工具绘制时没有对称地清除墙/障碍物。

## 修复

地形绘制时根据新地形类型对称清除旧标记：

```ts
} else if (tool === 'terrain') {
  if (terrainType === 2) {
    // 水：grid=1 标记为不可通过，清除 obstacleRef（水没有障碍物类型）
    grid[idx] = 1;
    obstacleRef.current.delete(idx);
  } else {
    // 非水地形（草/沙/石）：可通行，grid 归 0，清除 obstacleRef
    grid[idx] = 0;
    obstacleRef.current.delete(idx);
  }
  terrainRef.current.set(idx, terrainType);
}
```

## 行为表

| 操作序列 | 之前 | 之后 |
|----------|------|------|
| 砖 → 沙 | 砖覆盖沙 ✗ | 沙 ✓ |
| 砖 → 水 | 水（不被砖覆盖，之前已修）| 水 ✓ |
| 砖 → 草 | 砖覆盖草 ✗ | 草 ✓ |
| 水 → 沙 | 沙但 grid=1 ✗ | 沙 ✓（grid=0） |
| 沙 → 水 | 水 ✓ | 水 ✓ |
| 沙 → 砖 | 砖 ✓ | 砖 ✓ |

- `src/pages/MapEditor.tsx` — paintAtCell 中地形分支对称清除旧墙/障碍物标记
