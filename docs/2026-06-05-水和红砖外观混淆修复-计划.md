# 水和红砖外观混淆修复 - 2026-06-05

## 背景

用户反馈：水和红砖外观一样。

## 根因

水地形（terrain=2）被同时标记为：
- `terrainRef = 2`（水）
- `grid[idx] = 1`（墙，参见 [MapEditor.tsx paintAtCell](file:///d:/Projects/ant-cn/src/pages/MapEditor.tsx#L355) 的 `if (terrainType === 2) { grid[idx] = 1; }`）

渲染顺序（编辑器与游戏一致）：
1. **TerrainRenderer** 先画地形底色（水的蓝色 + 波浪）
2. **ObstacleRenderer** 在墙的格子上画障碍物纹理（红砖）

由于水格子的 `grid[idx] = 1`，被 ObstacleRenderer 当成墙处理，把红砖纹理直接覆盖在水纹上面 → 视觉上看起来就是红砖。

## 修复

障碍物渲染时跳过 terrain=2（水）的格子。水纹保留显示，但格子仍然是 wall=1（游戏逻辑里仍不可通过，与项目硬约束 "Water terrain is impassable and treated as a wall" 一致）：

```ts
// ObstacleRenderer.drawObstacles 和 MapEditor 渲染循环
if (cell.terrain === 2) continue;  // 水保留水纹
```

## 修改的文件

- `src/render/ObstacleRenderer.ts`
  - 类型签名扩展 `terrain?: number`
  - 渲染循环跳过 `terrain === 2` 的格子
- `src/pages/MapEditor.tsx`
  - 编辑器渲染循环同步跳过 `terrain === 2` 的格子

## 验证

- `npm run check` 通过
- 视觉：水格子不再被红砖覆盖，保留水纹
- 行为：水仍是 wall，蚂蚁仍不能通过
