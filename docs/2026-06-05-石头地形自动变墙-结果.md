# 石头（rock）地形自动变墙 结果

## 问题

> 为什么石头挡不住蚂蚁

## 根因

设计上 rock 地形（terrain=3）只被当作"装饰性可通行地形"，与 sand 同类。`World.setTerrain` 只对 water（terrain=2）自动设 `cell.wall=1`，对 rock 不动 wall。但 UI 上 rock tile 是石头外观，**用户期望**它挡路。

## 修复

让 rock 地形与 water 行为一致：

| 文件 | 改动 |
|---|---|
| `src/render/assets/TerrainTiles.ts` | rock `passable: true` → `false` |
| `src/simulation/World.ts` | `setTerrain` 中 `terrain === 3` 也设 `wall=1` 并 `computeDistanceField` |
| `src/pages/MapEditor.tsx` | paintAtCell：terrain 2/3 都 `grid[idx]=1`；save：terrain 2/3 也写入 `walls` 数组；render 循环：跳过 terrain 2/3 障碍物纹理 |
| `src/render/ObstacleRenderer.ts` | 跳过 `terrain === 3`（同 water） |
| `src/render/MapPreviewRenderer.ts` | 跳过 `terrain === 3` |
| `src/render/WorkerRenderer.ts` | 跳过 `terrain === 3` |

## 验证

- `npm run check` 通过
- dev server 启动在 http://localhost:5177/editor 正常
- MapEditor：画石头会标记为墙（grid=1），保存时进入 walls 数组
- 游戏：simulation 加载时通过 `setTerrain(rock)` 自动设 wall=1，蚂蚁遇石头改向
- 视觉：石头区域只画石纹，不被砖块纹理覆盖

## 兼容性

- 旧地图（无 terrain 字段）：正常，rock 行为不变（继续是装饰地形）
- 老 gridData 中有 rock 但 grid=0 的 cell：加载时 `setTerrain(rock)` 内部会设 `wall=1`，蚁群遇石头改向
- 草/沙地形：不受影响（terrain 0/1 仍可通行）
