# 石头（rock）地形应自动成为墙 计划

## 背景

用户反馈：石头（rock, terrain=3）挡不住蚂蚁。

## 现状分析

| 位置 | 当前行为 |
|---|---|
| [TerrainTiles.ts](file:///d:/Projects/ant-cn/src/render/assets/TerrainTiles.ts#L54-L65) | rock 定义 `passable: true`（语义上可通行） |
| [World.setTerrain](file:///d:/Projects/ant-cn/src/simulation/World.ts#L66-L79) | 仅 water (terrain=2) 自动设 `cell.wall=1`；rock (terrain=3) 不动 wall |
| [MapEditor paintAtCell](file:///d:/Projects/ant-cn/src/pages/MapEditor.tsx#L362-L374) | 画 rock 时 `grid[idx] = 0; obstacleRef.delete(idx); terrainRef.set(idx, 3)`，**未标记为墙** |
| [MapEditor save](file:///d:/Projects/ant-cn/src/pages/MapEditor.tsx#L519-L527) | 只把 `val === 1` 的 cell 写入 `walls` 数组，rock 因 `grid=0` 不进 walls |
| [simulation-worker](file:///d:/Projects/ant-cn/src/simulation/simulation-worker.ts#L283-L285) | 加载时调 `s.world.setTerrain(cx, cy, terrain)`，对 rock 不设 wall |
| [ObstacleRenderer](file:///d:/Projects/ant-cn/src/render/ObstacleRenderer.ts) | 跳过 `terrain === 2`（水），但 **未跳过 rock** |
| [MapPreviewRenderer](file:///d:/Projects/ant-cn/src/render/MapPreviewRenderer.ts) | 同样只跳过 water |
| [WorkerRenderer](file:///d:/Projects/ant-cn/src/render/WorkerRenderer.ts) | 同样只跳过 water |

## 根因

设计上 rock 是装饰性可通行地形（与 sand 同类），但 UI 上 rock tile 是石头外观，**用户期望**它和 water 一样挡路。

## 方案

让 rock 地形与 water 行为一致：
- 自动成为墙（不可通过）
- 不被 obstacle 纹理覆盖（保留 rock 视觉）
- 在 MapEditor 中画 rock 时同时标记 `grid=1`
- 在网格数据加载端通过 `setTerrain(rock)` 自动 `wall=1`

## 改动文件

1. `src/render/assets/TerrainTiles.ts` — rock `passable: false`
2. `src/simulation/World.ts` — `setTerrain` 中 `terrain === 3` 时也设 `wall=1` 并 `computeDistanceField`
3. `src/pages/MapEditor.tsx`:
   - paintAtCell: rock 时 `grid[idx]=1; obstacleRef.delete()`（同 water）
   - save: 把"terrain 2/3"也加入 `walls` 数组
4. `src/render/ObstacleRenderer.ts` — 跳过 `terrain === 3`（同 water）
5. `src/render/MapPreviewRenderer.ts` — 跳过 `terrain === 3`
6. `src/render/WorkerRenderer.ts` — 跳过 `terrain === 3`

## 验证

- `npm run check`
- 启动 dev server
- 编辑器：放石头 → 地图上画石头纹 → 保存 → 重新进入 → 蚂蚁遇石头改向
- 游戏画面：rock 区域蚂蚁无法穿越
- 旧地图（无 terrain 字段）仍正常
