# 统一地形/障碍/食物纹理渲染 结果

## 任务

> 地形和食物，障碍物的渲染只在编辑地图界面有， 选择地图和进入游戏界面中，均没有。

## 改动

### 1. worker 协议扩展 (src/simulation/worker-protocol.ts)

`WORLD_FLOATS_PER_CELL` 从 4 扩展到 8：
- 新增 4 字段：`terrain`、`obstacle`、`foodType`、`wearLevel`
- `WORLD_DIRTY_FLOATS_PER_CELL` 从 5 扩到 9

### 2. simulation-worker 序列化 (src/simulation/simulation-worker.ts)

`serializeCellData` 返回类型从 4 元改为 8 元。`serializeWorldFull` / `serializeWorldDirty` 写入 4 个新字段到 `worldBuffer` / `dirtyWorldBuffer`。

### 3. WorkerRenderer 完整 SVG 渲染 (src/render/WorkerRenderer.ts)

新增预加载 `terrainKeys` / `obstacleKeys` / `foodKeys` / `wornKey` 4 个 Map，复用 AssetRegistry。

`renderWorld` 改为分层：
1. 地形底图（terrain SVG 纹理，按类型分桶）
2. 障碍物纹理（按 obstacle 类型分桶，跳过 terrain=2 水）
3. 磨损土路（wearLevel > 0.3）
4. 信息素 markers（顶层覆盖）
5. 食物堆（NxN 锚点法 + 块大小映射 sprite）

`updateWorldData` 改为通用循环复制 8 个字段（兼容未来扩展）。

### 4. 新增 MapPreviewRenderer (src/render/MapPreviewRenderer.ts)

新类，给 GameSetup 等"无 World 实例"场景使用。
- 输入：gridData 解析后对象 + viewport
- 内部用 AssetRegistry.drawTile 画地形/障碍/食物
- 与 WorkerRenderer 共享 AssetRegistry 单例，纹理只加载一次

### 5. GameSetup 集成 (src/pages/GameSetup.tsx)

替换原 fillRect 灰色/绿色逻辑为：
```ts
if (parsedGridRef.current && previewRendererRef.current) {
  previewRendererRef.current.draw(ctx, parsedGridRef.current, vp, cw, ch);
}
```

新增 `previewRendererRef` 与 `parsedGridRef`，在 fetchMap 完成后填充。
GridData 类型扩展 `terrain` 字段（src/api/maps.ts）。

## 验证
