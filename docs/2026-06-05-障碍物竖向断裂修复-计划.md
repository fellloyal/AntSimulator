# 障碍物竖向断裂修复 - 2026-06-05

## 背景

用户反馈：障碍物只有横向时能连成一条线，竖向时就是很多个短横线，这个需要改进。

## 根因

[src/render/assets/ObstacleTiles.ts](file:///d:/Projects/ant-cn/src/render/assets/ObstacleTiles.ts) 4 种障碍物 SVG 都是 `width="24" height="12"`，即 **2:1 宽高比**：

```svg
<svg width="24" height="12" viewBox="0 0 24 12">
  <rect width="24" height="6" fill="#a04020" .../>   <!-- 顶行 1 块大砖 -->
  <rect y="6" width="24" height="6" fill="#8a3818" .../>  <!-- 底行 1 块大砖 -->
  <line x1="12" y1="0" x2="12" y2="6" .../>  <!-- 顶行中间分缝 -->
  <line x1="6" y1="6" x2="6" y2="12" .../>   <!-- 底行 1/3 分缝 -->
  <line x1="18" y1="6" x2="18" y2="12" .../> <!-- 底行 2/3 分缝 -->
</svg>
```

每个 SVG 表达的是"两块横向砖"的图案（顶行 2 块、底行 3 块错缝）。被 [AssetRegistry.preloadImage](file:///d:/Projects/ant-cn/src/render/AssetRegistry.ts) 拉伸到 128x128 缓存，再缩小到 cellSize（编辑器 4x4，游戏 20x20）时：

- **横向放置**：相邻 cell 的"两块砖"首尾拼接，砖缝对齐 → 看起来是一条连续的墙 ✓
- **竖向放置**：每个 cell 都重复同一"两块砖"图案，叠起来就是 2x2 像素的浅深色条 → 看起来是很多个短横线 ✗

## 修复

把 4 种障碍物 SVG 全部改为 **12x12 正方形 viewBox**，采用对称的 2x2 砖块布局（4 块砖/格，无错缝）：

```svg
<svg width="12" height="12" viewBox="0 0 12 12">
  <rect width="12" height="6" fill="#a04020" .../>
  <rect y="6" width="12" height="6" fill="#8a3818" .../>
  <line x1="0" y1="6" x2="12" y2="6" .../>   <!-- 水平中线 -->
  <line x1="6" y1="0" x2="6" y2="12" .../>   <!-- 垂直中线 -->
</svg>
```

这样无论横竖向放置，砖块图案都能在所有方向无缝拼接成连续线条。

围栏单独设计：上下两条横杆 (y=3, y=9) + 中间两根立柱 (x=3, x=9)，对称分布。

## 修改的文件

- `src/render/assets/ObstacleTiles.ts` — 4 个 SVG 全部从 24x12 改为 12x12 对称布局

## 验证

- `npm run check` 通过
- 横竖向连续性：4 方向都能拼接成连续线条（2x2 砖块图案）
