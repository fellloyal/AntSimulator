## 关键决策

- **同源打包 vs. 跨域加载**：选择前者，因 API 服务器对带 `Origin` 头的请求返回 403，无法在浏览器中通过 `<img crossOrigin>` 加载
- **提示词长度**：从 100+ 字符的详细描述（被 API 关键词过滤，返回 176626 字节固定默认图）改为 4-6 词的简洁短语（`red apple`、`fried chicken`、`bread loaf`、`blueberries`），每张图大小不一，证明确实生成了不同的图
