# 食物改为 Twemoji 矢量示意图 - 2026-06-05

## 背景

用户反馈"实物照片效果不理想"，要求改用"示意图"（标准 emoji 风格的矢量图）。同时检查发现 `text_to_image` API 对以下关键词有过滤：
- 单关键词（`apple`、`chicken`、`bread` 等）→ 固定 176626 字节默认图
- 风格词（`icon`、`illustration`、`emoji`、`kawaii`、`vector`）→ 同样被过滤
- 之前能工作的多词具体描述（`fried chicken drumstick with white bone` 等）也是照片风，不符合"示意图"诉求

## 方案

**改用 Twemoji 开源 SVG**

- 来源：https://github.com/jdecked/twemoji (Twitter 开源 emoji 库)
- 通过 jsDelivr CDN 下载（https://cdn.jsdelivr.net/gh/jdecked/twemoji@latest/assets/svg/）
- 用 Unicode 编码选择图标：
  - `1f357` → 鸡腿 🍗
  - `1f34e` → 红苹果 🍎
  - `1f35e` → 面包 🍞
  - `1fad0` → 蓝莓 🫐
- 文件大小：446-2431 字节（极小）

**为什么是 Twemoji**

- 标准 emoji 风格 — 全球用户都熟悉
- 矢量 — 任意缩放清晰，与现有 AssetRegistry 128x128 缓存兼容
- 开源 — 不依赖第三方 API 服务
- 离线嵌入 — 解决上一轮的 CORS 痛点
- 设计精良 — 由专业设计师团队打磨

## 实施

1. **下载 Twemoji SVG** → 放入 [src/render/assets/food_images/](./src/render/assets/food_images/)：
   - `apple.svg` (446B), `chicken.svg` (623B), `bread.svg` (542B), `berry.svg` (2431B)

2. **FoodSprites.ts 改用 `?raw` 引入 SVG 字符串**：

   ```ts
   import appleSvg from './food_images/apple.svg?raw';
   // ...
   export const FOOD_SPRITES = {
     0: { small: chickenSvg, medium: chickenSvg, large: chickenSvg },
     1: { small: appleSvg, medium: appleSvg, large: appleSvg },
     2: { small: breadSvg, medium: breadSvg, large: breadSvg },
     3: { small: berrySvg, medium: berrySvg, large: berrySvg },
   };
   ```

3. **preloadFoodSprite 自动识别**：
   - 检测 SVG 字符串 (`<svg` 开头) → `preloadSVG` (内部转 Blob URL)
   - 检测 URL (`http`/`data:`/`blob:`) → `preloadImage`

## 修改的文件

- `src/render/assets/FoodSprites.ts` — 改用 Twemoji SVG ?raw 引入
- `src/render/assets/food_images/{apple,chicken,bread,berry}.svg` — 新增 Twemoji SVG

## 验证

- `npm run check` 通过
- Vite dev server 5173 端口对 4 个 SVG `?raw` 返回 200 OK
- AssetRegistry 渲染路径不变：SVG → Blob URL → 128x128 缓存 → drawTile

## 经验

- **AI 图片 API 关键词过滤**：风格词（`icon`/`illustration`/`emoji`/`kawaii`）易被过滤；具体多词描述（`red apple with green leaf`）更可靠
- **示意图资源选型**：标准 emoji 库（Twemoji/Noto/EmojiOne）比 AI 生成更稳定，且矢量图无 CORS 问题
- **从照片 → 示意图**：风格反转时，优先选择设计一致的开源资源集（Twemoji），而非再用 AI 重新生成
