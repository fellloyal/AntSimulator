## 地图设计逻辑

### 1. 自然场景区 (上半 + 河流)
- **湖泊**：右上 50×30 cell 大水面，沙岸环完整但四角刻意留 1 cell 草地，制造 T 接点
- **河流**：横贯 120×11 cell 河面 + 1 cell 沙岸，**左右两端做收窄**避免硬切
- **沙岛**：湖中心 6×6 沙岛（mask 15 内部），外面是水（mask 0 沙岛外围）

### 2. 显式测试区 (左下 cx:35-60, cy:65-85)
- **凸角/凹角 4×2 = 8 个独立格**：每个角点单独测试，便于对照 reference
- **T 接点**：河流沙岸上挖 5×2 草地凹陷，形成 3 地形并存的尖角

### 3. 装饰区 (右下)
- **3 块岩石区 + 3 个单格岩石**：混合大小，验证草→岩 不同形态过渡

### 4. 障碍与食物点缀
- 河流沙岛上 2 道 2-cell 砖墙（验证障碍物+沙地形共存）
- 草地一堵 3-cell 砖墙
- 3 个 2×2 糖块分散放置

## 使用方法

### 在前端打开

1. 启动前端: `npm run dev` (Vite，端口 5173)
2. 启动后端: `cd server && npm run dev` (Fastify，端口 3001)
3. 浏览器打开 `http://localhost:5173`
4. 进入"地图选择"，可见 `autotile-demo` 记录
5. 点击"编辑" → 在地图编辑器中查看完整布局

### 验证 24-tile 资源

打开地图后，**湖岸四周的草地**应呈现：
- 朝水一侧：沙地伸出 2px 高的沙粒（feathering）
- 朝草一侧：草尖向沙地延伸

**河流沙岸**的两端应看到：
- 草地→沙地的硬切
- 沙地→水面的硬切
- 中间是连续的沙地

**左下测试区 (cx:35-60, cy:65-85)** 的 8 个 sand cell 应能看到：
- 4 个凸角：sand cell 角点处向对角方向凸出的小尖
- 4 个凹角：sand cell 角点处向内收的小缺口

## 风险与已知问题

- **地图布局偏"人造"**：为测试方便大量用几何形状（矩形/小岛），实际游戏地图会更自然
- **没有 3 地形在 1 cell 内**：所有 cell 是单一地形，无叠加（与项目设计一致）
- **缩略图为空**：本次没生成缩略图，地图选择界面会显示"暂无预览"
- **第 4 种地形（岩）覆盖度**：岩石只在右下区域集中，湖泊和河流附近没有岩石（避免视觉过杂）
