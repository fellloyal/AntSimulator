## 已知问题

### 生产构建（pre-existing，不在本任务范围）
`npm run build` 报 `Rollup failed to resolve import "@/common/math"` 错误。这是 Vite 6 worker 导入对 tsconfig path alias 支持的已知问题（worker 在打包时无法解析 `@/` 别名）。

**临时方案**：使用 dev server（`npm run dev`）验证，TypeScript 编译（`npm run check`）通过。

**修复建议**（待办）：在 vite.config.ts 中显式为 worker 链配置 `worker.plugins`，或在 worker 链中改用相对路径导入。
