# 蚂蚁模拟游戏 - 设计文档 2026-06-04

## 概述
将蚂蚁群体行为模拟器改造为模拟游戏，支持地图制作、保存、选择和游戏配置。

## 架构
- 后端：Fastify + SQLite（better-sqlite3），端口 3001
- 前端：React + TypeScript + Vite，端口 5174，代理 /api → 3001
- 数据：SQLite 存储地图，data/maps.db

## 页面流程
```
主菜单 ──┬── "制作地图" ──→ 地图编辑器 ──→ 保存 ──→ 主菜单
         └── "选择地图" ──→ 游戏配置 ──→ 开始模拟 ──→ 模拟器
```

## 后端 API
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/maps | 地图列表 |
| POST | /api/maps | 创建地图 |
| GET | /api/maps/:id | 获取地图详情 |
| PUT | /api/maps/:id | 更新地图 |
| DELETE | /api/maps/:id | 删除地图 |

## 数据库
```sql
CREATE TABLE maps (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  width INTEGER NOT NULL,
  height INTEGER NOT NULL,
  grid_data TEXT NOT NULL,
  thumbnail TEXT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

grid_data 格式（只存非空cell）：
```json
{ "cellSize": 4, "walls": [[cx,cy],...], "foods": [[cx,cy,qty],...] }
```

## 页面功能

### 主菜单 (MainMenu)
- 标题 + "制作地图" / "选择地图开始" 两个按钮

### 地图编辑器 (MapEditor)
- 顶部：地图名称、尺寸选择（小960x540/中1920x1080/大3840x2160）
- 中央：Canvas 画布，支持平移缩放
- 左侧工具栏：墙壁画笔、食物画笔、橡皮擦、笔刷大小
- 底部：保存、返回

### 游戏配置 (GameSetup)
- 左侧：地图列表（缩略图+名称+尺寸）
- 右侧：地图预览 Canvas，点击放置蚁巢
- 配置：蚁群数量(1-4)、工蚁/兵蚁数量
- 开始模拟按钮

### 模拟器 (Simulator)
- 保持现有功能
- 新增：加载地图数据初始化世界
- 蚁巢位置从配置读取
